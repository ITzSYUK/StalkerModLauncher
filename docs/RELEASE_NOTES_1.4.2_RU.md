# CORDON v1.4.2

## Исправления

- Исправлено положение панели профилей, открываемой из системного трея, на мониторах с повышенным масштабированием Windows.
- Координаты рабочей области и границ экрана теперь переводятся из физических пикселей в единицы WPF с учётом DPI. Панель корректно привязывается к трею при масштабе 125%, 150%, 175% и выше.

## Обновление

Распакуйте архив поверх предыдущей версии или используйте отдельную папку. Настройки и профили сохраняются.

## Архивы

- `CORDON-v1.4.2-win-x64-standalone.zip` — вариант с .NET 8 Desktop Runtime.
- `CORDON-v1.4.2-win-x64.zip` — компактный вариант; требуется .NET 8 Desktop Runtime x64.
